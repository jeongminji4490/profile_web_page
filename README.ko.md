# 개인 포트폴리오 웹사이트 (Personal Portfolio)

## 프로젝트 개요
- React 기반 SPA 구조로 개발한 개인 포트폴리오 사이트로, AWS S3를 이용하여 정적 웹사이트 형태로 배포
- 실제 웹 서비스와 유사한 구조로 배포 경험을 쌓기 위해 CloudFront, Route53을 활용한 웹 호스팅 및 도메인 연결 과정 구현

## 주요 기능

### 1. 페이지 구성
* **섹션 구성**: 개인 프로필/경력/프로젝트 소개
* **네비게이션**: 오른쪽 사이드바를 통해 페이지 전환 가능

### 2. 다국어 지원 (Localization)
* **i18n 적용**: `react-i18next` 라이브러리를 사용해 영어/한국어 번역 기능 구현
* **UX 최적화**: 브라우저 자동 번역보다 매끄러운 사용자 경험을 위해 직접 번역 데이터를 관리하며, 우측 하단 버튼으로 실시간 언어 변경이 가능하도록 구현

## 기술 스택

### Frontend
* **Framework**: React (JavaScript)
* **Routing**: 별도의 백엔드 서버 없이 정적 웹 호스팅만 할 계획이었기 때문에, 클라이언트가 라우팅을 처리하는 SPA 구조로 페이지 라우팅 구조 설계 (BrowserRouter 사용)
* **UI/UX**: 반응형 UI 적용 (Web/Mobile 대응)

### Deployment & Infrastructure
* **AWS S3**: 정적 웹사이트 호스팅
* **AWS CloudFront**: CDN을 통한 콘텐츠 캐싱 및 HTTPS(SSL/TLS) 보안 적용
* **AWS Route53**: 커스텀 도메인 생성 후 CloudFront에 연결

## 트러블슈팅

### SPA 라우팅 경로 인식 문제 (404/403 Error)
*   **문제 상황**: S3 또는 CloudFront 배포 환경에서 `/profile` 등 특정 경로로 직접 접속하거나 새로고침 시 404 에러 발생
*   **원인 분석**: 정적 파일 서버는 요청된 경로를 실제 파일 시스템의 경로로 인식하지만, SPA 구조상 해당 파일이 서버에 존재하지 않기 때문에 발생하는 문제임을 확인
*   **해결 방법**: CloudFront 및 S3 설정을 통해 모든 요청을 index.html로 fallback 처리하여 해결

## 프로젝트 성과
- AWS 기반 정적 웹사이트 배포 구조 이해 및 실습
- 성능 향상을 위한 CDN(CloudFront) 경험
- 도메인 연결 및 HTTPS 설정 경험 확보
- 실제 웹 서비스 배포 프로세스 전반 경험
